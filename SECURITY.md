# Security Policy

## Reporting a Vulnerability

Please do not open public issues or pull requests for security vulnerabilities.

Instead, email **macgyver.sp@pm.me** with:

- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- Affected version, commit, or branch
- Any suggested fix, if you have one

You should receive an acknowledgement within a few days. We will work with you
on a fix and let you know when it is released. Please give us a reasonable
chance to address the issue before disclosing it publicly.
